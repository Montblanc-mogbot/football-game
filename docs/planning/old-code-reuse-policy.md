# Old MonoGame code reuse policy

Updated: 2026-05-26

Default policy: **no reuse by default**.

This repo is a fresh-start assembly-first conversion. Work should begin from the original disassembly and current planning notes, not by importing code from an older MonoGame attempt.

If any old-code reuse is proposed later, it must be justified packet-by-packet against a named source-bank responsibility and added as an explicit new task first.
